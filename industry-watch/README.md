# Industry watch

Articles that watch the broader industry rather than evaluating a specific package. The signal that informs the "should we be in this ecosystem at all?" question — before the per-library reviews start.

The "how do I find the libraries to review?" article.
- [**Programming language popularity & desire**](language-popularity.md) — Stack Overflow 2025 rankings: what's used vs what's loved. Companion to the security-incidents review — both inform "which tech do we pick and commit to."
- [**Recent incidents in major technologies**](recent-incidents.md) — 2024-2026 CVE and supply-chain highlights across Next.js, WordPress, Python, npm, PyPI, and others. The "what can go wrong with the choices we already made?" article.
