## Conclusions and unknowns

The reliable production boundary is the approved source asset. An image service can propose a character and edit it using references. A coding agent can create or edit SVG, canvas code, or a WebGL scene. Neither approach guarantees that rerunning a natural-language brief produces the same geometry. A saved SVG does.

The evaluation should distinguish prompt adherence, repeated character identity, temporal identity in video, editable geometry, and operational replay. A single “quality” score hides those differences. No cross-provider winner is claimed without the repeat-and-review protocol in the article.

Unverified: account-specific availability, actual generation cost for this brief, visual rejection rates, exclusive rights, and native vector exports beyond the source-authored preview. These remain explicitly unknown rather than inferred from promotional galleries.
